# Repositorio-SO
**🚀 Tutorial de C++ para Principiantes - UNI**

¡Bienvenido al repositorio oficial del proyecto educativo de C++! Este material ha sido desarrollado para el curso de Sistemas Operativos de la Universidad Nacional de Ingeniería (UNI). Nuestro objetivo es guiarte desde "cero" hasta la creación de programas interactivos, desmitificando la complejidad de la gestión de memoria. 

**🎯 Objetivos del Proyecto**
- Superar el "muro de dificultad" inicial de C++ mediante una ruta de aprendizaje práctica. 
- Dominar la lógica computacional y la interacción del software con el hardware. 
- Aprender a gestionar recursos del sistema (memoria, punteros) de manera eficiente.

**📚 Estructura del Curso**

El repositorio está organizado de forma modular para separar la teoría de la práctica:
1. Fundamentos: Anatomía de un programa, variables y tipos de datos.
2. Control de Flujo: Toma de decisiones (if/else) y estructuras iterativas (for/while).
3. Gestión de Memoria: Uso de punteros (*) y direcciones (&).
4. Proyectos Prácticos:
- Calculadora básica.
- Generador de Fibonacci.
- Intercambio de variables (Swap) con punteros.
- Verificador de palíndromos.

**🛠️ Herramientas Necesarias**

Para compilar y depurar los ejemplos de este repositorio, recomendamos el siguiente ecosistema: 
- Compilador: GCC/G++ (Colección de compiladores de GNU). 
- Depurador: GDB (GNU Debugger) para inspeccionar la memoria en tiempo real. 
- Editor: Visual Studio Code con extensiones de C/C++.

**🚀 Cómo empezar**

Clona el repositorio:

_git clone https://github.com/tu-usuario/proyecto-cpp-uni.git_

Compila tu primer programa:

Navega a la carpeta del ejemplo y usa G++:

_g++ hola_mundo.cpp -o hola_mundo_

_./hola_mundo_
